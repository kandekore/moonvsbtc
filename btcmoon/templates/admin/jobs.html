Scheduled jobs

Jobs are idempotent: a second run of the same logical job on the same day is recorded as skipped rather than duplicated. They run from cron and need no browser session.

Commands

python -m jobs.morning_brief    # ~07:00 Europe/London
python -m jobs.evening_brief    # ~18:00 Europe/London
python -m jobs.ingest_news      # hourly
python -m jobs.daily_outlook    # publishes tomorrow's outlook as a draft
python -m jobs.snapshot_market  # daily market snapshot
python -m jobs.evaluate_protocols  # re-score frozen protocol windows
